# מסע בעולם

משחק עברי במגע, המיועד למסך KTC אופקי ביחס **16:9**. גרסת ה-PC מציגה בדיוק את אותה פריסה, עם התאמת גודל למסך וחללים בצדדים כשהיחס שונה. אין פריסה ייעודית ל-Galaxy Fold.

## פתיחה לבדיקה במחשב

לחצו פעמיים על **Open-Game.cmd**. הגרסה שכבר נבנתה תיפתח בדפדפן בכתובת <http://localhost:4173/>. להפעלה ממחשב אחר יש להתקין Node.js ולבנות את הגרסה:

```powershell
npm.cmd ci
npm.cmd run build
node scripts/preview-server.mjs
```

לחצו F11 בדפדפן לתצוגה במסך מלא, או השתמשו בכפתור מסך מלא בהגדרות. מקור ההתקנה של Node.js: <https://nodejs.org/>.

המוזיקה מתחילה עם פתיחת ביקור במדינה. בדפדפן חדש, שחזור ישיר של ביקור יכול להמתין לנגיעה הראשונה בתמונה בשל [מדיניות הניגון של Chrome](https://developer.chrome.com/blog/autoplay/). עצירה ידנית נשמרת במעבר בין תמונות; פתיחת ביקור מחדש מתחילה שוב את המוזיקה. באפליקציית Android הוגדר ניגון אוטומטי ללא צורך בנגיעה נוספת.

חלון ההפעלה מציג התקדמות ונסגר אחרי פתיחת הדפדפן. שרת משחק שכבר פועל מזוהה ונעשה בו שימוש; אם הפורט תפוס ביישום אחר, תופיע הודעת שגיאה ברורה. הבדיקות המקומיות מוגבלות בזמן ועוקפות פרוקסי של מערכת ההפעלה.

## מה כלול בגרסת הבדיקה

- 14 מדינות בכל שש היבשות: יפן, ישראל, צרפת, איטליה, גרמניה, אוקראינה, מצרים, מרוקו, ארצות הברית, קנדה, ברזיל, ארגנטינה, אוסטרליה וניו זילנד. באירופה ארבע מדינות ובכל יבשת אחרת שתיים.
- עד עשרה צבעים. כל דגל מציג רק את הצבעים הדרושים לו, עם מספרים רצופים החל מ־1 על הכפתורים והמשטחים. כל כפתור צבוע כולו בצבע שלו, עם מספר במרכז; בישראל כחול הוא 1 ולבן הוא 2.
- בחירת צבע מסמנת במשבצות אפורות את כל המשטחים המתאימים שטרם נצבעו. נגיעה צובעת רק משטח אחד, עם אנימציה עדינה.
- ארבע תשובות לזיהוי המדינה, ללא רמזים או קריינות.
- סדר המסע: צביעת הדגל, זיהוי המדינה, שש שאלות טריוויה, ולאחר מכן תמונות ומוזיקה. המדינה מתווספת לאלבום עם השלמת הטריוויה.
- צביעה נכונה ותשובה נכונה משמיעות צליל עדין ומציגות וי ירוק שקוף שנמוג. בחירה שגויה משמיעה צליל עדין ומרעידה לרגע רק את המשטח או את התשובה שנבחרו.
- השלמת צביעת הדגל וגם התשובה הנכונה לשאלת הטריוויה האחרונה מפעילות את אותה חגיגה: זיקוקים גדולים וקונפטי בשולי המסך למשך שתי שניות, עם קובץ הניצחון שסיפק בעל הפרויקט. קובץ `public/content/audio/victory.mp3` מנוגן במלואו, ללא שינוי בהקלטה, ופועל ללא רשת. הדגל נשאר גלוי והכפתורים פעילים; תנועה מצומצמת מציגה קישוט צבעוני קבוע בשוליים. יציאה מהמסך או מעבר לרקע עוצרים את הצליל.
- מגן הדוד בדגל ישראל הוא משטח ממוספר לצביעה. יש לו אזור נגיעה רחב והוא נשאר מעל הרקע הלבן בכל סדר צביעה.
- עשרים תמונות מקומיות לכל מדינה, המתקדמות בנגיעה בתמונה: עיר הבירה, ערים מרכזיות, נופים ואתרים מוכרים. לכל 14 המדינות יש מוזיקה מקומית בקובצי MP3 שנוצרו ב־Suno וסופקו עבור המשחק. המוזיקה מתחילה אוטומטית עם פתיחת הביקור ואפשר לעצור ולהפעיל אותה בכפתור. שמות הקבצים החדשים מפורטים ב־[רשימת המדינות החדשות](docs/added-countries.md).
- שש שאלות טריוויה קלות לכל מדינה, עם ארבע תשובות ושאלה אחת בכל פעם, לפני פתיחת התמונות. תשובה שגויה מאפשרת ניסיון נוסף, ותשובה נכונה פותחת מעבר לשאלה הבאה בקצב השחקן, בלי מגבלת זמן או ציון. התשובה הנכונה השישית מפעילה את חגיגת הסיום ומציגה כפתור „לתמונות ולמוזיקה”. שאלות שכבר נענו נשמרות כשעוזבים או מרעננים. אפשר גם לשחק שוב בטריוויה מתוך התמונות והאלבום.
- בכל יבשת מוצג מונה ביקורים בפורמט 3/8, לפי המדינות שמופעלות בהגדרות. בחירה אקראית מציעה רק מדינה שטרם נכנסה לאלבום. יבשת שהושלמה מוצגת באפור עם וי ופותחת את האלבום שלה.
- אלבום מסע נשמר אוטומטית ומחולק ליבשות: מדינות שביקרו בהן מוצגות כדגל, ומדינות שטרם ביקרו בהן במסגרת עם סימן שאלה. אפשר לפתוח שוב מדינה מהאלבום, לצפות בתמונות ולהפעיל מוזיקה.
- משחק חוזר מכל מדינה באלבום מתחיל באותו דגל כשהוא ריק. איפוס האלבום דורש אישור בתוך המשחק, ואפשר לבטל את האיפוס מיד לאחריו. ההגדרות והסבב הפתוח נשמרים.
- הגדרות: קבוצת מדינות, בחירה אישית, שלושה מחווני עוצמה עצמאיים למוזיקה, לצלילי תגובה ולתרועת ניצחון, ותנועה מצומצמת. מחווני העוצמה נשמרים גם לאחר פתיחה מחדש. לצלילי התגובה ולתרועת הניצחון יש כפתורי השמעה לבדיקה; עוצמה של אפס משתיקה אותם. ברירות המחדל הן 35% למוזיקה, 70% לצלילי תגובה ו־20% לתרועת ניצחון.
- שמירת סבב פתוח, כולל המשטחים שנצבעו, ההתקדמות בטריוויה והצילום הנוכחי.

כל משאבי הבדיקה מקומיים, כולל פונט Heebo. ייחוס התמונות והרישיונות מופיעים בהגדרות וב-`public/content/credits.json`.

שאלות הטריוויה כלולות גם בקוד וגם בקטלוג המקומי, ופועלות ללא רשת. מקורות העובדות מופיעים ב-[docs/trivia-sources.md](docs/trivia-sources.md). קטלוגי תוכן ישנים ללא טריוויה נשארים נתמכים.

הנחיות וקטעי מוזיקה מוצעים נמצאים ב-[docs/music.md](docs/music.md). אפשר להחליף קטעי בדיקה בקובצי MP3/WAV באמצעות `scripts/replace-music.mjs`, שמסנכרן את קובץ המדיה, הקטלוג והקרדיטים.

## עבודה ללא רשת ועדכונים

אפליקציית Android אורזת את משאבי הבדיקה בתוך ההתקנה. בדפדפן, לאחר פתיחה ראשונה של גרסת הבנייה, Service Worker שומר את הממשק ואת כל המדיה; בהגדרות מופיע כשהתוכן מוכן לבדיקה ללא רשת. מצב גלישה פרטי או חסימת אחסון עשויים למנוע שמירה בדפדפן.

האפליקציה בודקת עדכון ברקע בכל פתיחה ובחזרה מהרקע, כשמוגדרת כתובת פרסום ויש חיבור לאינטרנט. אם נמצא עדכון, מוצג חלון ״הורדת העדכון״ / ״לא עכשיו״. תוכן וקובצי התקנה יורדים רק לאחר אישור. חבילות תוכן נבדקות בשלמותן לפני הפעלה. הורדה שנקטעה משאירה את התוכן הקודם, והפעלה נדחית עד שאין סבב פתוח. האלבום וההגדרות נשמרים בנפרד מחבילות התוכן. חבילות נתונים כוללות תמונות, מוזיקה וקטלוג; שינוי בקוד המשחק מפורסם כגרסת אפליקציה.

בבנייה דרך GitHub Actions, מקור העדכונים מוגדר אוטומטית כקובץ `release-manifest.json` המצורף לגרסה החתומה האחרונה. לפיתוח בדפדפן הגדירו את `VITE_UPDATE_MANIFEST_URL` ב-`.env.local`; בגרסה מקומית ללא כתובת עדכון המשחק נשאר זמין ללא רשת והממשק אינו מציג בדיקה מוצלחת כשאין מקור עדכונים.

יצירת קובץ עדכונים מהתוכן המקומי:

```powershell
node scripts/prepare-updates.mjs --base-url=https://YOUR-PUBLIC-HOST/content/ --content-version=0.1.1 --output=release-manifest.json
```

## Android והפצה

הקוד והוראות ההפצה נמצאים ב-[android/README.md](android/README.md). להגדרה החד־פעמית פתחו `SETUP_SIGNING.cmd`, והדביקו את הערך שהועתק כסוד GitHub Actions בשם `WORLD_GAME_SIGNING`. המפתח הפרטי וגיבויו נשמרים ב־`.release-private` ומוחרגים מ־Git. לאחר ההגדרה, כל Push ל־main בונה APK חתום, מאמת את החתימה ויוצר גרסה להורדה עם קובץ עדכונים תואם. הקישור הקבוע לוואטסאפ הוא <https://github.com/ancorossie1708/world-game/releases/latest/download/world-game.apk>. המעבר מגרסת הבדיקה לחתימה הקבועה מחייב הסרה חד־פעמית של גרסת הבדיקה; לאחר מכן העדכונים מתקינים מעל הגרסה החתומה ושומרים את האלבום וההגדרות, בכפוף לאישור Android.

APK **טרם נבנה או נבדק על מכשיר** בסביבת העבודה הנוכחית: Java וכלי Android אינם מותקנים בה. הבנייה והבדיקות המקומיות מכסות כרגע את גרסת ה-PC, מבנה התוכן ומנגנוני השמירה והעדכון. תיקיית Android ותהליך CI מוכנים לבדיקת הבנייה ב-GitHub.

## בדיקות

```powershell
npm.cmd run build
npm.cmd test
```

הבדיקות מכסות צביעת משטח יחיד, ארבע תשובות ייחודיות, בחירת מדינה, שחזור נתונים פגומים, שימור אלבום, אימות חבילות ועדכון שנקטע. בנוסף נבדק רצף המשחק בדפדפן בפריסה 1920×1080.
