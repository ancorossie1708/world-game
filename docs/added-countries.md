# מדינות חדשות ומוזיקה

לכל מדינה נוספו דגל לצביעה, שש שאלות טריוויה ו־20 תמונות מקומיות. המדינות החדשות מסומנות כמוכרות וזמינות גם בבחירת ״מדינות מפורסמות״.

| יבשת | מדינה | קובץ המוזיקה ששולב |
|---|---|---|
| אפריקה | מצרים | egypt.mp3 |
| אפריקה | מרוקו | morocco.mp3 |
| צפון אמריקה | ארצות הברית | usa.mp3 |
| צפון אמריקה | קנדה | canada.mp3 |
| דרום אמריקה | ברזיל | brazil.mp3 |
| דרום אמריקה | ארגנטינה | argentina.mp3 |
| אוקיאניה | אוסטרליה | australia.mp3 |
| אוקיאניה | ניו זילנד | new-zealand.mp3 |

את הקבצים יש לשים בתיקייה `public/content/audio` של הפרויקט. לאחר קבלתם יש להריץ את `scripts/replace-music.mjs` לכל מדינה, כדי לעדכן גם את הקטלוג המובנה, הקטלוג להורדה והקרדיטים. אין צורך לשנות את האלבום.

כל שמונת קובצי ה־MP3 התקבלו ושולבו ב־13 באוקטובר 2026. לכל 14 המדינות במשחק יש כעת מוזיקה משלהן. כל הקבצים נבדקו בפענוח מלא, נשמרו כפי שסופקו ונכללים בחבילה לשימוש ללא רשת. המוזיקה מתחילה אוטומטית בביקור ומכבדת את עוצמת המוזיקה שבהגדרות. סימוני ההמתנה הוסרו מהקטלוג ומהקרדיטים.

מידע על האתרים ושאלות הטריוויה נבדק מול אתרי התיירות הרשמיים וגורמי ממשל:

- מצרים: [אתר התיירות הרשמי](https://www.experienceegypt.eg/en/home), [הנילוס והערים שעל גדותיו](https://www.experienceegypt.eg/en/region/12/the-nile).
- מרוקו: [לשכת התיירות הרשמית](https://www.visitmorocco.com/fr/).
- ארצות הברית: [פסל החירות](https://www.nps.gov/stli/index.htm), [הגרנד קניון](https://www.nps.gov/grca/index.htm).
- קנדה: [הדגל ועלה האדר](https://www.canada.ca/en/canadian-heritage/services/flag-canada-description.html), [אוטווה ומעמדה כבירה](https://ottawa.ca/en/city-hall/city-manager-administration-and-policies/office-protocol/office-protocol-procedures/flag-protocol-procedures).
- ברזיל: [ברזיליה](https://www.visitbrasil.com/location/brasilia/), [סמבה והאמזונס](https://www.visitbrasil.com/en/index.html).
- ארגנטינה: [טנגו בבואנוס איירס](https://www.argentina.travel/en/activities/tango-in-buenos-aires), [פטגוניה ומאטה](https://argentina.travel/en/about-argentina).
- אוסטרליה: [קנברה](https://www.australia.com/en/places/australian-capital-territory.html), [אתר התיירות הרשמי](https://www.australia.com/en-us).
- ניו זילנד: [ולינגטון](https://www.newzealand.com/au/wellington/), [אתר התיירות הרשמי](https://www.newzealand.com/nz/).

לכל תמונה יש כתובת מקור ב־Wikimedia Commons, יוצר ורישיון בקטלוג וב־`credits.json`. דגלי המדינות מבוססים על דגלי Wikimedia Commons; המספרים ומשטחי המגע נוספו לצורך המשחק. פרטי הסמלים הקטנים מאוגדים למשטחי צביעה נגישים.
